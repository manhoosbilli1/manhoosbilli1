## Physical Pomodoro Timer

The Physical Pomodoro Timer is a hardware-based productivity tool designed to implement the Pomodoro technique. Built with an Arduino microcontroller, it features a custom PCB, LEDs, a buzzer, and buttons for user interaction. The timer cycles through 25-minute work periods and 5-minute breaks, with visual and auditory cues to signal transitions. The schematic and PCB were designed using tools like EasyEDA, ensuring a compact and reliable build. The firmware, written in C++, handles timing logic and user inputs, with provisions for saving settings. <br>
Project Link: https://github.com/manhoosbilli1/Pomodora_timer

## RGB Laser Projector
The RGB Laser Projector, your final year project, is an advanced optics system combining red, green, and blue lasers through a dichroic x-cube to create vibrant displays. Controlled by an STM32 microcontroller, it uses galvanomirrors for precise beam steering and raster scanning. The firmware, written in C, implements PWM for color mixing, UART for serial debugging, and integrates with Python scripts for data analysis and spectroscopy. The project showcases your skills in embedded systems, optics, and signal processing, with applications in displays and scientific instrumentation. Accompanied by a LaTeX thesis. <br>
Project Link: https://github.com/manhoosbilli1/Laser_Projector
